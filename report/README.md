# Report directory

Use this directory for report source material and the final PDF.

Recommended structure:

1. Introduction
2. Dataset description
3. Data quality and preprocessing
4. Statistical and correlation analysis
5. PCA methodology
6. PCA results
7. Cross-dataset discussion
8. Conclusion

Store selected publication-ready figures under `report/figures/` and compact result tables under `report/tables/`.
