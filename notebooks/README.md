# Notebook responsibilities

Create the following notebooks during implementation:

1. `01_wine_quality.ipynb`
   - data integration
   - data-quality audit and cleaning
   - descriptive statistics and correlation
   - standardization and PCA
   - explained variance and visualizations

2. `02_heart_disease.ipynb`
   - missing-value and categorical preprocessing
   - data-quality audit and cleaning
   - descriptive statistics and association analysis
   - encoding, standardization, and PCA
   - explained variance and visualizations

3. `03_pca_comparison.ipynb`
   - component-count comparison
   - cumulative-variance thresholds
   - original-versus-PCA comparison
   - compact tables used by the final report

Each notebook should be executable from top to bottom after the raw data files are placed under `data/raw/`.
